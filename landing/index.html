Ingeniería

Stack técnico

⚙️

Backend

FastAPI + Python 3.12

API REST async. Endpoints: /diagnose, /chat, /health, /models. uv para gestión de dependencias.

🗄️

Vector DB

pgvector · PostgreSQL 16

Búsqueda híbrida 70% semántica (cosine) + 30% keyword (ILIKE). Filtro obligatorio por modelo de equipo.

🤖

LLM + Vision

OpenRouter · multi-modelo

Modelo intercambiable vía .env sin rebuild. Vision habilitada para análisis de fotos. Recomendado: Mistral Small.

🧠

Embeddings

MiniLM-L12-v2 multilingual

paraphrase-multilingual-MiniLM-L12-v2 · 384 dims · soporte nativo español. Chunking 800 chars, overlap 100.

⚛️

Frontend

React 18 + Tailwind + Vite

Mobile-first. Cámara nativa para capturar foto del equipo. Chat RAG conversacional. Remotion video player.

☁️

Infraestructura

InsForge · Docker Compose

PostgreSQL gestionado en InsForge (pgvector incluido) + storage de PDFs. Docker local: make docker-up. Deploy en Railway / Fly.io.

Preguntas frecuentes

Todo lo que necesitas saber

No. AnclaIA es una herramienta de apoyo — el técnico sigue siendo quien diagnostica y ejecuta la reparación. La IA entrega contexto estructurado basado en el manual oficial para que el técnico llegue preparado al buque, con las herramientas correctas y sin perder tiempo.
El sistema siempre indica el nivel de confianza (ALTA / MEDIA / BAJA) y cita la página exacta del manual de donde proviene la información. Con 31.000+ chunks indexados de manuales oficiales Furuno, los diagnósticos de alta confianza son muy fiables. Si la confianza es BAJA, el sistema lo indica explícitamente y recomienda revisión directa del manual.
Actualmente el sistema requiere conexión para consultar el LLM. Para zonas con baja conectividad (alta mar) estamos evaluando un modo offline con modelos más pequeños embedidos. Es parte del roadmap para Q3 2025.
El MVP indexa manuales Furuno (FAR1523, FAR1518, FAR2127, FCV628, FA170, FM8900S y más). La arquitectura es agnóstica a la marca — se puede indexar cualquier manual técnico en PDF. Raymarine, Garmin y Simrad están en el roadmap. Si tienes manuales de otro fabricante, contáctanos.
