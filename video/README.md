# AnclaIA — Video Explicativo (Remotion)

Video de 46 segundos que explica el proyecto AnclaIA usando [Remotion](https://remotion.dev).

## Escenas

| # | Título | Duración |
|---|--------|----------|
| 0 | Intro — Logo + título | 4s |
| 1 | El Problema | 6s |
| 2 | La Solución | 6s |
| 3 | Stack Técnico | 6s |
| 4 | Demo UI (typewriter) | 6s |
| 5 | Resultado del diagnóstico | 7s |
| 6 | Modelo de negocio | 6s |
| 7 | Outro / CTA | 5s |

## Setup

```bash
cd video
npm install

# Previsualizar en Remotion Studio
npm run dev

# Renderizar a MP4
npm run render
```

## Salida

El video se renderiza en `out/anclaia-demo.mp4` (1280×720, 30fps, H.264).
